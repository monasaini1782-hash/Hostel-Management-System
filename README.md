# 🏠 Hostel Management System

A desktop application built with *Java Swing* and *MySQL* to manage hostel students, rooms, fees and employees in one place.

## ✨ Features

*Student Management*
- Manage rooms with automatic Booked / Not Booked status
- Add new students and allot rooms
- Search, update and delete student records by mobile number
- Record student fees
- View all living and leaved students

*Employee Management*
- Add new employees
- Search, update and delete employee records
- Record monthly employee payments
- View all working and leaved employees

*Other*
- Login authentication
- Logout, Exit and Shut Down options

| Area | Technology |

| Connectivity | JDBC (MySQL Connector/J) |
| IDE | Apache NetBeans |

## 🚀 How to Run

1. Install *JDK* and *MySQL*.
2. Create a database named hostel and import hostel.sql.
3. Open the project in *NetBeans*.
4. Make sure the *MySQL Connector/J* jar is added to the project Libraries.
5. In ConnectionProvider.java, replace your_password with your own MySQL password.
6. Run the project.
